## 🚀 Como Usar

### Quick Start

```bash
# 1. Abrir no navegador
open index.html

# OU com servidor local
python -m http.server 8000

# OU com Node.js
npx http-server
```

### Customização

1. Edite `index.html` para mudar conteúdo
2. Edite `css/style.css` para cores
3. Edite `js/script.js` para adicionar funcionalidades
4. Substitua imagens por suas próprias

Veja `CUSTOMIZATION_GUIDE.md` para detalhes.

## 🐛 Troubleshooting Rápido

| Problema | Solução |
|----------|---------|
| Imagens não carregam | Verifique URLs, use https, teste internert |
| Menu não funciona | F12 → Console, procure erros |
| Formulário não envia | Configure backend, verifique console |
| Animações lentas | Reduza duração no AOS, verifique CPU |
| Layout quebrado | Limpe cache, teste mobile, F12 DevTools |

Veja `QUICK_START.md` para mais detalhes.
